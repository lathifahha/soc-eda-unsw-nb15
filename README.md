# SOC EDA Project — UNSW-NB15 Dataset

## About
Exploratory Data Analysis of the UNSW-NB15 cybersecurity dataset as part of a SOC Data Analytics portfolio project.

## Dataset
UNSW-NB15 — University of New South Wales Network Intrusion Dataset
Source: https://research.unsw.edu.au/projects/unsw-nb15-dataset

## Tools Used
Python | pandas | matplotlib | seaborn | Jupyter Notebook

## Key Findings
- The dataset contains a significant proportion of malicious traffic (31.9%), making it relevant for intrusion detection analysis.
- The TCP protocol dominates the traffic, indicating that most network activity and attacks target TCP based services.
- There is a perfect correlation between the number of packets and the number of bytes, indicating feature redundancy and a strong relationship in traffic volume.

## How to Run
1. Clone this repo
2. Download UNSW-NB15 CSV and place in same folder
3. Open notebook in Jupyter and run all cells
